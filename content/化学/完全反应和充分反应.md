|          | **完全反应**            | **充分反应**                |
| -------- | ------------------- | ----------------------- |
| **本质**   | 反应物按计量比**恰好耗尽**，无剩余 | 反应进行到**最大程度**（某反应物耗尽即止） |
| **关键特征** | 所有反应物同时归零           | 至少一种反应物耗尽，另一种可能有剩余      |
| **计算场景** | 求"恰好完全"时的质量比        | 判断过量、求产率、算剩余            |
