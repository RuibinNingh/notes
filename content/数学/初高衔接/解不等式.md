# 一元多次不等式
## 图像法
对于一个一元 $n$ 次不等式,假设其有 $n$ 个实根
$$a_nx^n+a_{n-1}x^{n-1}+\cdots+a_1x+a_0>0$$
其中$a_n\ne 0,\quad n\in \mathbb{N}^*$  
我们令 $f\left( x \right)=a_nx^n+a_{n-1}x^{n-1}+\cdots+a_1x+a_0$

尝试对 $f(x)$ 进行因式分解,可得
$$f\left( x \right) =a_n\left( x-x_1 \right) \left( x-x_2 \right) \cdots \left( x-x_n \right) $$
根据 $n$ 的奇偶性我们可以想象出函数的大体图像  
此时根据图像可以写出解集
# 分式不等式
分式不等式一般是类似这样的
$$\frac{f_1\left( x \right)}{f_2\left( x \right)}>n$$
## 处理方法
两边同时乘 $\left( f_2\left( x \right) \right) ^2$ 得
$$f_1\left( x \right) f_2\left( x \right) >n\left( f_2\left( x \right) \right) ^2$$
如果 $n \ne 0$ ,可以选择移项,合并同类项变成这样的形式
$$f_3\left( x \right) >0$$
接下来可以尝试因式分解等操作得到解,进而通过图像法获得范围

> [!warning] 注意  
> 分式不等式必须先考虑定义域：  
>  
> $$  
> f_2(x)\ne 0  
> $$  
>  
> 这个条件在约分、平方、同乘分母平方、以及处理 $\geqslant$、$\leqslant$ 时尤其重要
>  
> 分子为 0 的点，在 $\geqslant 0$ 或 $\leqslant 0$ 中可能可以取  
> 分母为 0 的点，永远不能取

# 绝对值不等式
绝对值不等式是类似
$$\left| f_1\left( x \right) \right|>f_2\left( x \right) $$
的不等式
## 分类讨论
我们很容易想到绝对值的性质,由此可以分类讨论
$$\begin{cases}
f_1(x)>f_2(x)\\
f_1(x)\ge 0
\end{cases}
\quad\text{或}\quad
\begin{cases}
-f_1(x)>f_2(x)\\
f_1(x)<0
\end{cases}$$
## 平方法
如果 $$\forall x\in D,\quad f_2(x)\geqslant 0$$
可以将两边平方
$$\left( f_1\left( x \right) \right) ^2>\left( f_2\left( x \right) \right) ^2$$
利用平方差公式,得
$$\left( f_1\left( x \right) +f_2\left( x \right) \right) \left( f_1\left( x \right) -f_2\left( x \right) \right) >0$$
此时就变成一个一元多次不等式,一般借助图像法解决
## 图像法
这是一种通用解法,比较暴力  
直接画出 $y=|f_1(x)|$ 和 $y=f_2(x)$ 的函数图像  
求一下交点就能轻松得到,不过有些费事
## 根式不等式
对于$$\sqrt{f_1\left( x \right)}>f_2\left( x \right) $$
我们需要根据 $f_2(x)$ 的正负进行分类讨论  
容易得到
$$
\sqrt{f_1(x)}>f_2(x)
\iff
\begin{cases}
f_1(x)\ge 0\\
f_2(x)<0
\end{cases}
\quad\text{或}\quad
\begin{cases}
f_1(x)>\left(f_2(x)\right)^2\\
f_2(x)\ge 0
\end{cases}
$$
